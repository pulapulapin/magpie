# Magpie

Save links, video, audio and pages on your Mac.

- Website: https://pulapulapin.github.io/magpie/
- **Report a bug:** [open an issue](https://github.com/pulapulapin/magpie/issues/new?template=bug_report.yml)

This repository contains the Magpie website and its bug tracker only. The app itself is not open source.

---

Magpie：在 Mac 上保存链接里的视频、音频和文章。本仓库只包含网站和 Bug 反馈，应用本身不开源。
