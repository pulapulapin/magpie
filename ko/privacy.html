개인정보 처리방침

최종 업데이트: 2026-10-19

한 문장으로

Magpie는 모든 작업을 사용자의 Mac에서 처리합니다. 계정, 사용 통계, 광고, 충돌 보고가 없으며, 저장한 콘텐츠를 수집하거나 수신하거나 업로드하지 않습니다. App Store에서 Magpie의 개인정보 보호 라벨은 “데이터 수집 없음”입니다.

데이터가 있는 곳

데이터위치참고
저장한 동영상·오디오·글·파일사용자가 선택한 폴더(기본값: 다운로드/Magpie)사용자의 Mac에만 있습니다
라이브러리 기록·설정·진행 상황Magpie의 앱 데이터 폴더사용자의 Mac에만 있습니다
웹사이트 로그인 상태앱 창 전용 웹 데이터Mac에만 있으며 도움말에서 언제든 삭제할 수 있습니다

Magpie가 인터넷에 연결될 때

사용자가 어떤 동작을 했을 때만 연결합니다.

  • 링크를 저장할 때: 지정한 웹사이트와 해당 사이트의 미디어 서버에 연결합니다.
  • 구매 또는 구매 복원(App Store 버전): 구매는 Apple이 처리합니다.
  • 직접 판매 버전만 해당: “업데이트 확인”을 누르면 GitHub의 yt-dlp 릴리스 페이지에 연결합니다. BitTorrent 링크는 DHT와 트래커에 연결하며 다른 피어에게 IP 주소가 보입니다. 선택 사항인 음성 모델은 사용자가 확인한 뒤에만 내려받습니다.

Magpie는 저희 서버로 아무것도 보내지 않습니다. 저희는 서버를 운영하지 않습니다.

구매와 라이선스

App Store 버전: 결제·영수증·환불은 Apple의 개인정보 처리방침에 따라 Apple이 처리하며, Magpie는 구매가 유효한지 여부만 알게 됩니다. 직접 판매 버전: 라이선스 키는 앱에 내장된 공개 키로 Mac에서 검증하며, 활성화할 때 서버에 연결하지 않습니다.

웹사이트 로그인

로그인이 필요한 사이트에서는 사용자가 앱 창에서 직접 로그인합니다. Magpie는 비밀번호를 읽거나 저장하지 않으며, 로그인 상태는 사용자가 저장을 요청한 콘텐츠를 가져오는 데에만 사용합니다.

클립보드

클립보드 알림은 기본적으로 꺼져 있습니다. 켜면 Magpie는 링크를 인식하기 위해 링크만 읽으며 그 밖의 내용은 보관하지 않습니다.

사용자의 선택

  • 도움말에서 언제든 웹사이트 로그인 상태를 삭제할 수 있습니다.
  • Magpie의 앱 데이터 폴더를 삭제하면 모든 기록이 지워집니다.
  • 저장한 파일은 사용자의 것이며 언제든 삭제할 수 있습니다.
