ひとことで言うと

Magpie の処理はすべてお使いの Mac の中で行われます。アカウント、利用状況の収集、広告、クラッシュレポートはありません。保存したコンテンツを収集・受信・アップロードすることもありません。App Store での Magpie のプライバシーラベルは「データの収集なし」です。

データの保存場所

データ場所備考
保存した動画・音声・記事・ファイルお客様が選んだフォルダ（初期値：ダウンロード/Magpie）お使いの Mac の中にとどまります
ライブラリの記録・設定・進行状況Magpie のアプリデータフォルダお使いの Mac の中にとどまります
Web サイトのサインイン状態アプリウインドウ専用の Web データMac の中にとどまります。ヘルプからいつでも消去できます

Magpie がインターネットに接続するとき

お客様の操作があったときだけです。

  • リンクを保存するとき：指定された Web サイトと、そのサイトのメディアサーバに接続します。
  • 購入または購入の復元（App Store 版）：購入処理は Apple が行います。
  • 直販版のみ：「アップデートを確認」を押したときに GitHub の yt-dlp リリースページへ接続します。BitTorrent のリンクでは DHT とトラッカーに接続し、他のピアにお客様の IP アドレスが見えます。任意の音声モデルは、確認後にのみダウンロードされます。

Magpie は当方のサーバに何も送信しません。当方はサーバを運用していません。

購入とライセンス

App Store 版：決済・領収・返金は Apple のプライバシーポリシーに従って Apple が処理し、Magpie は購入が有効かどうかだけを知ります。直販版：ライセンスキーはアプリに内蔵された公開鍵で Mac 上で検証され、認証時にサーバへ接続しません。

Web サイトへのサインイン

サインインが必要なサイトでは、お客様自身がアプリウインドウでサインインします。Magpie はパスワードを読み取ったり保存したりしません。サインイン状態は、お客様が保存を指示したコンテンツの取得にのみ使います。

クリップボード

クリップボードの通知は初期状態でオフです。オンにすると、Magpie はリンクを認識するためにリンクだけを読み取り、それ以外は保持しません。

お客様の選択

  • ヘルプからいつでも Web サイトのサインイン状態を消去できます。
  • Magpie のアプリデータフォルダを削除すると、すべての記録が消えます。
  • 保存したファイルはお客様のものです。いつでも削除できます。
